## Agent skills

### Issue tracker

Issues are tracked in this repository's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

The tracker uses the default five-role triage label vocabulary. See `docs/agents/triage-labels.md`.

### Domain docs

Domain documentation uses a single-context layout. See `docs/agents/domain.md`.

### APIM policy comments

When editing XML policies, add concise intent comments before each `<choose>`, `<when>`, and `<otherwise>` branch. Describe what the condition represents and why the branch action is correct, especially for fail-closed sequencing.
